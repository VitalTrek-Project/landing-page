# VitalTrek Landing Page

This is the official landing page for the VitalTrek project, an IoT platform for extreme adventure tourism in Peru.

## About the Project

VitalTrek connects adventurous tourists and tour agencies in a smart ecosystem that monitors location, vital signs, and progress in real time, even without a signal.

### Features

*   **For Tourists**:
    *   Complete offline navigation with downloadable maps.
    *   Wearable device integration for vital signs monitoring.
    *   Automatic recording of the experience with geotagged photos and notes.
    *   Contextual tour information.
*   **For Agencies**:
    *   Live dashboard to manage all tours from one place.
    *   Automatic alerts for anomalies.
    *   Post-tour reports to optimize routes and experiences.
    *   Asynchronous synchronization for offline operation.
